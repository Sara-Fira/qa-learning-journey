# QA Learning Portfolio

This repository contains my QA portfolio projects covering manual web application testing and REST API testing.

The projects include test planning, test cases, execution results, defect and issue reporting, exploratory testing, and Postman collections.

## Tools

* Postman
* Swagger / OpenAPI
* TestRail
* Jira Cloud
* Confluence
* Chrome DevTools
* GitHub
* Markdown

## Projects

### [SauceDemo Manual Testing](projects/saucedemo-manual-testing)

Manual testing project covering login, product catalogue, cart, and checkout workflows.

### [OrangeHRM Manual Testing](projects/orangehrm-manual-testing)

End-to-end Manual QA project covering 40 functional test cases, exploratory testing, role-based workflows, Jira defect reporting, and TestRail execution evidence.

### [Swagger Petstore API Testing](https://github.com/Sara-Fira/swagger-petstore-api-testing)

REST API testing project covering all 19 documented Pet, Store, and User operations.

The project includes positive and negative tests, dynamic test data, Postman assertions, end-to-end workflows, Collection Runner execution, and documented API issues.

## About

These projects were created for learning and portfolio purposes and do not represent commercial work experience.
