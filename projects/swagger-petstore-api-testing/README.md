# Swagger Petstore API Testing

## Project Status

**In progress**

## Project Overview

This project covers functional API testing of the Swagger Petstore API using Postman.

The project includes positive and negative test scenarios, dynamic test data, environment and collection variables, and end-to-end workflows for Pet, Store, and User resources.
